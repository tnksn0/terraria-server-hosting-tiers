## 自己电脑开服为什么撑不住

泰拉瑞亚的多人模式本质上是局域网发现机制：同一网段里的设备才能互相看见房间，一跨网，好友的“加入”列表就是空的。想走公网，得把 7777 端口映射出去，前提是有公网 IP，运营商给不给还得另说；或者自己搭一条内网穿透隧道。为了开一局游戏研究一晚上路由器，多数人折腾一次就不想再来第二次。

更麻烦的是“房主即服务器”。世界数据跑在房主电脑上，房主关电脑，服务器就没了。用本机开服，实际会遇到几个问题：

- 电脑必须一直开着，夏天散热噪音和电费都是成本
- 自家宽带上行有限，人一多就卡，跨运营商延迟还会翻倍
- 关机、断网、系统更新重启，全员掉线，存档可能停在半路
- 没有固定 IP，每次开服都要重新通知朋友新地址

还有一种更常见的僵局：做主机的人这周加班没空上线，其他人就推不动进度。把服务端搬到机房之后，这四件事同时消失，服务器有固定 IP，你不在线它也在跑，Boss 的血量留在上次打到一半的位置。

3. 进控制台，下拉到 MCSManager 面板，按提示启动服务器。
4. 可选参数写在启动脚本末尾：`-maxplayers 8` 限制人数、`-password 你的密码` 加密码、`-difficulty 1` 设难度（0 经典 / 1 专家 / 2 大师 / 3 旅程）、`-language zh-Hans` 让服务端输出中文。

连不上时先查两处。一是安全组或系统防火墙有没有放行 7777（泰拉瑞亚默认端口，改过就以游戏界面显示的为准）；二是朋友填的地址对不对，别把内网地址当成公网 IP 发出去。

## 哪些人不需要租云服务器

有两种情况，买云服务器是浪费钱。

**只想今晚开一局，朋友都在同一个城市。** 用蒲公英游戏版组一张虚拟局域网就行：房主建房后记下组网 IP（172.16.x.x 开头，不是 192.168.x.x），点【马上联机】，再进游戏开服；队友加入房间、也点【马上联机】，游戏里“加入”填房主的组网 IP 加端口 7777。顺序别搞反，所有人先联机成功再启动游戏，房主先开服、队友后连接。它的限制也明确：免费房间 5 人（含房主），Mac 暂时不支持，只有 Windows / Android / iOS 三端；虚拟 IP 每次登录可能变化；房主关机，世界就没了。临时开黑够用，长期固定服不合适。

**有 Linux VPS，只跑 tModLoader，愿意自己维护。** 有个开源面板 tml-panel（MIT 协议）把 tML 的运维做成了网页操作：一键装本体、工坊搜模组自动补前置依赖、本体一键升级带失败回滚、世界自动备份、可视化改配置、网页里发游戏命令。代价要看清：它只管一台单实例服，裸机 systemd 方案，需要 root 权限，面板密码等同于 root，默认只监听 127.0.0.1，要访问得走 SSH 端口转发；内存 2G 起，装灾厄这类大模组要 4G。省下的是钱，付出的是自己管 Linux 和 root 风险。

## FAQ

**tModLoader 能跑吗？** 能。更新服务端文件后改一下启动脚本就行，全程面板操作，不用 Linux 知识。MOD 服对单核主频要求更高，优先选 Ryzen 系列。

**选哪个机房？** 大陆玩家选宿迁、十堰、广州，延迟低；跨境或含香港玩家选香港机房，走 BGP 优化线路。同队玩家分散在南北两地时，优先选离常驻人数最多的那批人近的机房。

**会被 DDoS 打吗？** 游戏云内置 BGP 高防，有基础防护。普通私服被打的情况不多，如果你之前被盯上过，选防御力度更高的机房套餐。

**只玩几天怎么办？** 支持动态计费，玩家不在线时 CPU 消耗低，系统自动少收费；另外有 1 元体验选项。注意这类按日、按电量的非月付消费按官方政策不支持退订。

**服务器开着没人玩会不会一直扣钱？** 动态计费模式下闲置消耗低，扣得少。长期 24 小时满负载的固定队，固定计费反而更稳，两种模式使用期间可以切换。
